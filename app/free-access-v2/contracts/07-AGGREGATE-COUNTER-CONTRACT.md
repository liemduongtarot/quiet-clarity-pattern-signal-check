# Aggregate-first product measurement

Event → direct integer increment → discard event detail. The analytics module accepts only fixed counter names, never arbitrary properties or dimensions. It has no access to quota tokens, token hashes/signatures/derivatives, browser IDs, execution receipts, raw content or payment identity.

Core finite product names: `psc_started`, `psc_result_valid_committed`, `psc_result_copy_succeeded`, `psc_result_download_initiated`, `quota_cycle_started`, `quota_cycle_reached_2`, `quota_cycle_reached_3`, `quota_cycle_reached_4`, `quota_blocked`, `paid_bridge_rendered`, `paid_bridge_opened`. Optional direct exhaustion totals are `time_to_exhaust_under_1h`, `time_to_exhaust_1h_to_24h`, `time_to_exhaust_24h_to_720h`. The quota service computes one coarse bucket at the fourth success and passes only the constant counter name. No elapsed time or token is passed. No cycle number, time-between-results or long-lived event journey.

`psc_started` is first questionnaire interaction per loaded page. Browser actions send POST `/api/metrics` with exactly `{event}` and `credentials: omit`, no raw data or cookies. Only start/copy/download/bridge names are accepted there; client cannot mint authoritative result/quota transitions. Copy event follows successful clipboard promise; denial/failure emits no success. Download is initiation of a user-directed Blob download, never proof of permanent download or storage. Refresh does not consume quota; repeat actions count actions, not distinct people. No event identity is introduced to deduplicate aggregate UX actions.

Authoritative result/transition counters are incremented by the quota service once per issued receipt, never on replay. `quota_blocked` counts blocked execution attempts, not unique people or cycles. Analytics cannot control access or result semantics. Failed aggregate writes can undercount; no retry may double count an already-recorded receipt. No event log is kept for repairing telemetry.

No classification/status counters in this specimen: no governed classification/status taxonomy is present. If later admitted, only existing governed outputs may increment independent coarse totals. Never retain rows combining timestamp, classification, status, market, language, use number or experiment variant. Never infer psychology.

Sparse-dimension control: zero visitor/event/time/market/language/variant dimensions in storage. No public metrics-reading endpoint. Operator export suppresses totals below 20 and coarsens released totals to multiples of 20; raw-count access is restricted technical/qualification access, not anonymous published analytics. These are engineering safeguards, not a universal anonymity proof. Production public release, cohort sufficiency, repeated-snapshot differencing and retention are OPEN pending separate governance; this task publishes only synthetic qualification aggregates. Never market small live counters as anonymous statistics.

Aggregate counters persist only as constant name + integer total. No analytics SDK, event buffer, precise event rows, session replay, browser ID or quota-linkage layer. Synthetic adversarial tests send forbidden extra properties, arbitrary counter names, quota/token/hash and raw text and must reject without persisting them.
