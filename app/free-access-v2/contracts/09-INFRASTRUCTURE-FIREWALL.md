# Processing infrastructure firewall

All PSC input and recovered/output result exchanges use encrypted POST bodies in production. GET quota/health/static contain no raw content. Remove GET reading/list/reopen. Reject query strings and unrecognized paths with fixed errors and never echo them. Browser never constructs a URL/query/route/analytics field from input/result. Responses/errors/questionnaire pages and result-download delivery where applicable use `Cache-Control: no-store`; client download uses an ephemeral Blob and promptly revokes its URL, with no cached server file or raw-data URL.

Actual TLS is required in production; spoofed `X-Forwarded-Proto` is not trusted. The only HTTP exception is explicit local loopback synthetic qualification, with a separate cookie name and no real personal input. This exception cannot operate in NODE_ENV=production or for a non-loopback origin/peer. CSP, no-referrer, nosniff, frame denial and same-origin opener protections are retained. Strict same-origin POST checks, JSON media type/body-size bounds and exact payload fields prevent accidental cross-origin writes and unwanted data surfaces. No account/login integration.

No request/access/body logging. Never log URL/query, cookies, quota token, receipt, raw input/result, error.message from unknown dependencies or stack traces. Public API errors are fixed allowlisted messages/codes and minimal safe quota/retry metadata only. Fixed startup/health technical fields may report mock-only status; no user input is interpolated. No raw content in trace attributes, crash reports, support tooling, session replay, screen recording or dead-letter queues. Test stdout/log-capture adversaries must prove raw marker/token absence.

No service worker, localStorage, sessionStorage, IndexedDB, analytics SDK or third-party browser asset is introduced. Autocomplete/spellcheck disabled for the questionnaire; pagehide clears raw textarea, result DOM and active receipt, including back-forward cache restore handling. HTTP no-store is necessary but is not a guarantee against OS memory/swap, browser extensions, user clipboard/files or hostile screenshots. No such unsupported guarantee is made.

Production reverse proxy/CDN/load balancer/model provider must honor the same no-body/no-token/no-query-log rules and no-cache policy. No infrastructure is deployed in this task. Vendor defaults are not approval. Infrastructure access logs, crash dumps, backups, swap and data locations must be reviewed before deployment, not claimed verified by local tests.

Future external-model contract (not implemented): no training, no secondary use, minimum available retention, documented subprocessors, documented processing/data location and transfer position, no human review except separately governed incident handling, encrypted POST only, no sensitive logs/caches, abort/deadline support and raw-content deletion. These are admission requirements; no claim is made that any unnamed provider currently satisfies them. No model key or live provider call is required or allowed.
